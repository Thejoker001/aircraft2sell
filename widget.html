Un widget simple pour les partenaires

Aéroclubs, brokers et revendeurs : affichez vos annonces Aircraft2Sell directement sur votre propre site. Le widget se met à jour automatiquement à chaque annonce publiée, sans aucune maintenance de votre côté.

  • Renseignez l'email du compte vendeur qui publie vos annonces sur Aircraft2Sell.
  • Cliquez sur « Générer le code », puis copiez le code affiché.
  • Collez-le dans le code HTML de votre site, à l'endroit où vous voulez voir vos annonces.

Le widget affiche les 10 dernières annonces en ligne du vendeur : photo, modèle, année et prix, avec un lien vers la fiche détaillée sur aircraft2sell.eu. Utilisation libre pour les partenaires Aircraft2Sell.
